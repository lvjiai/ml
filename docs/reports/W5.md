# W5 报告：区间在域偏移下的存活情况（仿真内部）

> 目的：不是证明"我们的区间在新工况下依然好用"，而是量出**它从哪一步开始不可信、怎么救、代价多大**。
> 全部实验留在 C-MAPSS 内部，每一步只增加一个变量，便于归因。跨设备（MetroPT-3）已由 ADR 0001 明确排除。

## 1. 实验协议

- 源域：`FD001`（1 个工况、1 种故障模式）。在 fit 单元上训练 GBDT，用 `select_model` 选出 73 轮；在源 calib 单元上得到 conformal 分位数 `q_src = 24.086`（α = 0.10）。
- 目标域：`FD002`、`FD004`（6 个工况、2 种故障模式）。目标域**不参与训练**，只做归一化/校准上的适配。
- 便携特征：去掉 `setting_1..3` 与 `condition` 后的 378 维，保证源域模型能在目标域上直接推理（settings 的取值集合在域间不同）。
- 评估：每个测试单元的**末周期**，`y = min(RUL, 125)`，与点模型训练标签的截断保持一致。
- 校准点采样：目标域训练单元第 30 周期起、stride 10，只保留 `RUL ≤ 150` 的点（与 W4 同协议）。
- α = 0.10，覆盖率目标是 0.90；随机性只来自 `seed=42` 的 `select_model` 与单元抽样。

五个阶段，严格递进：

| 阶段 | 名称 | 做了什么 |
|---|---|---|
| E1 | 同分布 | FD001 训练 + FD001 归一化 + FD001 校准 → FD001 测试（上界参照） |
| E2 | 朴素迁移 | 源归一化 + 源校准直接搬到目标域 |
| E3 | 无监督适配 | 用目标域训练集的传感器（无标签）拟合工况归一化，其余同 E2（transductive，见 ADR 0002） |
| E4 | 少样本重校准 | E3 + k 台目标域**有标签**单元重算 `q` |
| E5 | 扰动 | 在 E3 基线上加噪声 / 丢传感器（s_4、s_11、s_12、s_7 的特征置 0） |

## 2. 结果

### 2.1 主表（覆盖率 / 平均宽度 / 点 RMSE）

| 阶段 | FD001→FD002 | FD001→FD004 |
|---|---|---|
| E1 同分布 | 0.860 / 48.2 / 16.20 | 0.860 / 48.2 / 16.20 |
| E2 朴素迁移 | **0.390** / 48.2 / 40.00 | **0.367** / 48.2 / 39.36 |
| E3 无监督适配 | 0.672 / 48.2 / 26.50 | 0.673 / 48.2 / 24.07 |
| E4 k=1 | 0.985 / 116.8 | 0.778 / 60.6 |
| E4 k=3 | 0.876 / 92.2 | 0.778 / 60.7 |
| E4 k=10 | 0.876 / 92.9 | 0.968 / 94.0 |
| E4 k=50 | 0.869 / 89.9 | 0.879 / 78.8 |
| E5 噪声 0.3 | 0.649 / 48.2 / 26.85 | 0.657 / 48.2 / 26.10 |
| E5 传感器丢失 | 0.548 / 48.2 / 28.62 | 0.504 / 48.2 / 32.08 |

宽度列在 E1–E3、E5 恒为 48.2，是因为这些阶段只换了输入/检验集，没有重算 `q`：区间宽度由源域的 `q` 决定，不会自动跟着目标域的错误分布变化——这正是问题所在。

### 2.2 分段覆盖率（E3 vs E4 k=50）

`cov_0_30` 是最要命的一段（RUL < 30 周期，临近失效）：

| 阶段 | FD002 | FD004 |
|---|---|---|
| E3 | 1.000（n=60） | 0.942（n=52） |
| E4 k=50 | 1.000 | 0.981 |

E3 在低 RUL 段反而"覆盖得很好"，但这是**假的好**：整个区间宽 48 周期，低 RUL 段的真值本来就落在里面；同时 80–200 段只有 0.42 / 0.55。区间没有随不确定性变化，只是被一个过宽的常数撑住了。

## 3. 归因

1. **E2 的崩塌（0.86 → 0.39）不是"模型太差"，而是 conformal 的前提没了**。`q_src` 是在源域误差分布上标定的；目标域的误差分布整体右移（点 RMSE 从 16 涨到 40），而 `q` 没变，于是覆盖率必然掉。这是共形预测在**协变量偏移**下的已知局限，不是实现 bug。
2. **E3 救回一半（0.39 → 0.67）**：FD002/FD004 的 6 个工况让传感器均值/方差成簇偏移，按工况 z-score 后大部分偏移被消掉（点 RMSE 40 → 26.5 / 24.1）。剩下的差距来自"工况内"的分布差异与故障模式不同。
3. **E4 能把覆盖率拉回 0.88–0.97，但宽度涨到 1.7–2.4 倍**，且随 k 非单调：k 小时抽到的单元决定 `q`（k=1 时 FD002 的 `q` 高达 58.4，覆盖率 0.985 其实是过度保守）；k 增大后 `q` 趋稳，但目标域单元间差异大，覆盖率的方差仍不小。**"覆盖率恢复"是用区间宽度换来的，不是免费的。**
4. **E5 说明区间对输入退化没有免疫力**：加噪 0.3 让覆盖率再掉 0.02–0.03；丢掉 4 个信息量最大的传感器后掉到 0.50–0.55，低 RUL 段 FD002 只剩 0.15——区间完全不覆盖。

## 4. 这对"仿真→真实"意味着什么

- 如果真实设备的工况不在训练分布里，**直接搬用仿真标定的区间会系统性失准，且失准方向是"过于自信"**（覆盖率 0.39 而名义 0.90）。
- 部署时必须保留一个**有标签的在线校准集**（E4），否则区间数字不可信；无监督适配（E3）只能救回一部分。
- 少样本重校准的代价要写进使用说明：k≈10 时宽度约为同分布情形的 1.9 倍，等于用"更宽的区间"换"可信的覆盖率"。

## 5. 局限

- 点模型始终是 FD001 训练的，E3/E4 只动归一化与校准，没有在目标域上重训——这是有意的（否则测不出"只靠适配能走多远"），但也意味着 E3/E4 的 RMSE 不代表目标域的上限。
- E4 的 k 台单元是随机抽的，只跑了一个 seed；k 小时的抖动应视为抽样噪声而非规律。
- E5 的噪声是加在**特征**上的高斯噪声，不是传感器物理退化模型，量级只能做相对比较。
- 只有 FD001→FD002/FD004 两个方向；FD003 未做（与 FD001 同工况，信息量低）。
