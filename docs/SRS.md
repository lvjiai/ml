# 需求规格说明书（SRS）

**项目**：sim2real-rul —— 从仿真到真机的工业设备剩余寿命预测与可信区间
**版本**：v0.1（草案；§4.5 跨域协议待 MetroPT-3 数据核实后定稿）
**日期**：2026-10-23
**状态**：待评审

---

## 1. 引言

### 1.1 目的

本文档定义「sim2real-rul」项目的需求边界、功能与非功能需求、验收标准与里程碑。它是后续设计、实现、验收的唯一依据；与本文档冲突的实现视为缺陷。

### 1.2 范围

**做**：

- 在 NASA C-MAPSS 涡扇发动机退化仿真数据上，构建剩余寿命（RUL）预测模型；
- 用 conformal 方法给出带覆盖保证的预测区间，并与朴素区间方法对照；
- 在真实工业数据（UCI MetroPT-3，地铁压缩空气系统）上检验"仿真域训练的模型迁移到真实域"的性能落差，并量化解释落差来源；
- 交付一个可交互的单曲线演示（输入传感器序列 → RUL + 区间）；
- 交付一份中文、偏学术的报告。

**不做**：

- 不做实时流式推理、不做云端部署、不做多设备联合调度；
- 不采集任何非公开数据、不使用个人数据；
- 不追求 SOTA 排行榜名次，追求"可解释的落差"与"可信的区间"。

### 1.3 术语

| 术语 | 定义 |
|---|---|
| RUL | Remaining Useful Life，从当前时刻到失效的剩余循环数 |
| 仿真域 | C-MAPSS 生成的涡扇发动机退化数据 |
| 真实域 | MetroPT-3 采集的地铁压缩空气系统运行数据 |
| 落差（gap） | 同一模型/同一任务在真实域相对仿真域的性能下降 |
| 点预测 | 单一 RUL 数值估计 |
| 预测区间 | 带覆盖保证的区间 [lo, hi]，目标覆盖率 1−α |
| split conformal | 用留出校准集的分位数构造区间的 conformal 方法 |
| CQR | Conformalized Quantile Regression，先做分位数回归再用 conformal 校准 |
| 覆盖率 | 测试样本中真实值落入预测区间的比例 |
| 区间宽度 | hi − lo 的均值，衡量区间是否"有用" |
| NASA score | C-MAPSS 官方的非对称评分函数，低估比高估惩罚更重 |

### 1.4 参考

- Saxena et al., *Damage Propagation Modeling for Aircraft Engine Run-to-Failure Simulation*（C-MAPSS 原始论文）
- C-MAPSS 数据包内 `readme.txt` 与 `Damage Propagation Modeling.pdf`
- Romano, Patterson, Candès, *Conformalized Quantile Regression*, NeurIPS 2019
- Angelopoulos & Bates, *A Gentle Introduction to Conformal Prediction*, 2021
- UCI Machine Learning Repository: MetroPT-3（id 791）

## 2. 总体描述

### 2.1 产品视角

一个**分析型工程项目**：主线是"仿真基准上的好成绩，到真实产线上还剩多少"，模型是证据，区间是交付物。演示只是把结论变得可触摸，不是产品。

### 2.2 用户与角色

| 角色 | 关注点 |
|---|---|
| 项目作者（学生） | 理解每一行代码、能讲清方法与结论 |
| 验收者（作者本人/答辩场景） | 三条硬线是否达标 |
| 演示观众（同学/老师） | 输入一条曲线，能否得到可信的 RUL 与区间 |

### 2.3 运行环境

- 操作系统：Windows 11
- 硬件：仅 CPU（无可用 GPU），内存 ≥ 16 GB
- 语言/运行时：Python 3.13，虚拟环境
- 依赖：pandas、numpy、scikit-learn、lightgbm、torch（仅 LSTM 对照用）、streamlit、matplotlib
- 网络：仅用于一次性下载数据集；训练与演示全程离线可复现

### 2.4 设计约束

- C1：所有数据必须可公开获取且许可允许再分发结果（C-MAPSS 为 NASA 公开数据；MetroPT-3 许可待核实）。
- C2：全流程必须在 CPU 上于可接受时间内完成（见 NFR-1）。
- C3：不设硬性截止日期；按周交付可验收增量。
- C4：报告为中文，偏学术，需包含方法、实验、讨论与局限。

### 2.5 假设与依赖

- A1：C-MAPSS 的官方训练/测试划分与 `RUL_FD00x.txt` 标签可直接使用。
- A2：RUL 标签按惯例截断于 125（超过 125 的视为 125），该假设需在报告中说明并做敏感性检查。
- A3：MetroPT-3 的真实域任务形态尚未确定（见 §4.5 与 §9 的 TBD-1），本版文档不锁定其协议。

## 3. 功能需求

优先级：M = 必须，S = 应当，C = 可选。

### 3.1 数据管道

| ID | 需求 | 优先级 | 验收方式 |
|---|---|---|---|
| FR-1.1 | 下载并校验 C-MAPSS 压缩包（约 12.4 MB，外层 zip 内含 `CMAPSSData.zip`），校验文件大小与行数 | M | 脚本输出四个子集的行数：20631 / 53759 / 24720 / 61249 |
| FR-1.2 | 解析 `train_FD00x.txt`、`test_FD00x.txt`、`RUL_FD00x.txt`，统一为长表 schema：`unit, cycle, setting_1..3, s_1..s_21` | M | 单元测试 + schema 断言 |
| FR-1.3 | 生成训练标签：每条记录 `RUL = max_cycle(unit) − cycle`，并截断至 125 | M | 抽样核对首尾记录 |
| FR-1.4 | 处理常数列/近常数列（C-MAPSS 中有传感器在部分子集恒定），在报告中列出剔除清单 | S | EDA 输出表 |
| FR-1.5 | 提供可复现的数据划分（训练/校准/测试），固定随机种子 | M | 两次运行划分完全一致 |

### 3.2 仿真域建模

| ID | 需求 | 优先级 | 验收方式 |

| FR-2.5 | 模型选择只在训练/校准内进行，测试集只用于最终评估一次 | M | 流程审计（日志） |

| ID | 需求 | 指标 |

## 7. 验收标准（三条硬线）

项目"做完"当且仅当以下三条同时成立：

1. **演示可用**：任取 FD001–FD004 的一条测试曲线（或上传同格式 CSV），界面在 2 秒内给出 RUL 点预测与区间，并对区间宽度给出解释；错误输入不崩溃。
2. **落差可量化**：报告包含"仿真域 vs 真实域"的对比表（至少 1 个性能指标 + 区间覆盖率），并对差距给出至少两条有数据支撑的解释。
3. **一键复现**：在干净环境中执行一条命令，从原始数据生成报告所需的全部图表与表格；抽查 3 个数字与报告一致。

附加质量线（不达标不算失败，但需在报告中说明）：

- Q1：CQR 在测试集上的实际覆盖率 ≥ 0.88（目标 0.90）；
- Q2：CQR 的平均区间宽度不超过 split conformal 的 1.1 倍，且覆盖率不低于其 0.02；
- Q3：主模型 RMSE 优于全部基线。

## 9. 风险与开放问题

| ID | 风险 | 影响 | 缓解 |
|---|---|---|---|
| R1 | **TBD-1**：MetroPT-3 可能无法构造 RUL 式目标 | 主线"落差"可能退化为"预警提前量" | 核实后以 ADR 锁定替代协议；提前准备降级方案 |

| R5 | MetroPT-3 许可不明确 | 结果不可公开 | 核实许可；不明确则只在报告中引用不重分发 |
